Ajuda · Como funciona o Flashcard

Flashcards são pares de pergunta e resposta. Você revisa repetidamente para fixar o conteúdo.

  • Crie cards manualmente ou com IA.
  • Importe CSV/JSON e organize por coleções.
  • Estude marcando acertos/erros e dificuldade.
  • Use o modo prova para treinar com múltipla escolha e revisar explicações.
  • Use desafios e compartilhe coleções com links.
  • Acompanhe logs e foco das sessões.

Minhas Provas

Como importar provas

CSV/XLSX: use o formato gerado em Baixar em “Minhas Provas”.

Obrigatório por questão: question, option_1…option_4, correct.

Em correct, use A/B/C/D (ou 0–3 / 1–4). Para duas corretas: A,C.

Use exam_id para separar múltiplas provas no mesmo arquivo.

Exemplo (CSV):

question,option_1,option_2,option_3,option_4,correct,explanation
	O que é TCP?,Protocolo de transporte,Protocolo de roteamento,Memória RAM,Formato de arquivo,A,TCP é um protocolo de transporte.
	Qual porta padrão do HTTP?,21,80,443,25,B,HTTP usa a porta 80 por padrão.

Modelo para IA (copie e cole):

Gere uma prova de múltipla escolha em CSV com cabeçalho:
question,option_1,option_2,option_3,option_4,correct,explanation

Regras:
- 4 alternativas por questão (option_1..option_4), sem campos vazios
- correct deve ser A/B/C/D (ou A,C para 2 corretas)
- explanation curta (1–2 frases) justificando o gabarito
- Não inclua texto fora do CSV

Importe arquivos gerados em “Baixar” (CSV/XLSX).

Meus Cards

Como importar

CSV: precisa ter colunas question e answer. Exemplo:

question,answer
	O que é SQL?,Linguagem para bancos relacionais

JSON: array de objetos ou objeto com cards:

[
	  { "question": "O que é Python?", "answer": "Uma linguagem de programação" }
	]

Modelo para IA (copie e cole):

Gere flashcards em CSV com cabeçalho:
question,answer

Regras:
- 1 card por linha
- question e answer obrigatórios (sem campos vazios)
- Não inclua texto fora do CSV

Após carregar, use o mapeamento para indicar quais colunas são pergunta e resposta.

Evite arquivos muito grandes e revise se não há linhas vazias.
